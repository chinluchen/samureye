戰鬥畫面 UI 調整清單

一、只改 CSS
1. 敵方圖片
- 放大右上角敵方圖片
- 調整到更靠右上
- 保留現有圖片來源與顯示邏輯，只改尺寸、位移、陰影、裁切方式

2. 敵方血條
- 保留在上方區塊
- 調整成更靠左的位置，與敵方圖片形成左右分佈
- 調整寬度、間距、文字對齊

3. 回合倒數大數字
- 調整中央倒數的字級、位置、層級
- 讓它更像獨立的戰鬥回合倒數，而不是其他演出字樣

4. 我方圖片
- 調整左下角我方圖片大小與位置
- 保持背面圖顯示方式

5. 我方 HP / MP
- 調整底部面板的高度、欄位寬度、數值對齊
- 保留目前已存在的 HP / MP 數值，不刪除

6. 技能按鈕區
- 調整底部三個技能按鈕的大小、間距、底部貼齊方式
- 讓按鈕區更接近目標畫面中的主操作區

7. 整體畫面層級
- 調整 z-index、safe area、透明度、邊距
- 讓敵方圖、倒數、我方圖、技能按鈕的視覺主次更清楚

二、需要調整元件排列，但不要碰戰鬥邏輯
1. HudLayer.vue
- 重新整理敵方血條與敵方圖片的相對位置
- 重新整理我方圖片、PLAYER ID、HP、MP 的視覺順序
- 可以調整 DOM 順序，但不要改 id

2. PvpBattleView.vue
- 如果只是傳遞顯示用圖片 props，可以維持現狀
- 不要在這裡改戰鬥流程或事件觸發時機

3. App.vue
- 只保留目前已經存在的數值與圖片來源傳遞
- 不要改 timer、傷害、技能施放、同步、倒數開始的邏輯

三、絕對不要動
1. 錨點 id
- enemy-hp-anchor
- player-hp-anchor
- skill-bar-anchor
- cutscene-layer

2. 已被邏輯引用的 class / 位置
- .player-avatar-figure
- .cutscene-portrait
- .cutscene-skill-name

3. 會影響戰鬥流程的邏輯
- 倒數開始與結束
- 技能施放時間
- 傷害與回合切換
- input lock / resume timer
- 教學焦點定位
- 技能特效定位

四、建議的修正順序
1. 先只調 CSS，先把整體比例拉近目標畫面
2. 再微調 HudLayer 的元件順序
3. 最後只在必要時，才碰 App.vue 的 props 傳遞

五、目前要保留的資訊
- 敵方 HP 數值要保留
- 我方 HP 數值要保留
- 我方 MP 數值要保留
- PLAYER ID 要保留
- 回合倒數要保留
- 三個技能按鈕要保留
